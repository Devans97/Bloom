# BLOOM Rebuild — Decision Log

**Project:** BLOOM (CBSE Class XII Board Examinations 2027)  
**Learner:** Aastha  
**Primary Device:** iPad | **Secondary:** Phone  
**Design Direction:** Premium Pink Apple-inspired Liquid Glass  

| Decision ID | Date | Status | Topic | Decision & Rationale |
|---|---|---|---|---|
| D01 | 2026-11-21 | **Confirmed** | Scope | Strictly CBSE Class XII Board Examinations (2027). All JEE content, metrics, problem sets, and weightage are strictly excluded. |
| D02 | 2026-11-21 | **Confirmed** | Subjects | Exactly five board subjects: Physics (042), Chemistry (043), Mathematics (041), English Core (301), and Physical Education (048). Yoga is part of PE Unit 3, never an independent 6th subject. |
| D03 | 2026-11-21 | **Confirmed** | Learner Account | Aastha is the sole user. No public registration, multi-user system, or parent/requester dashboard. |
| D04 | 2026-11-21 | **Confirmed** | Actionable Tasks | Eliminate all generic "Prepare [chapter]" tasks. Every task must provide action verb, scope, purpose, ordered steps, verified NCERT/curriculum references, duration, completion evidence, and understanding reflection. |
| D05 | 2026-11-21 | **Confirmed** | Study Workspace | Clicking an activity opens an interactive study workspace containing step checklists, sourced resource references, mistake capture, and self-reflection (Easy/Okay/Difficult). |
| D06 | 2026-11-21 | **Confirmed** | Availability Matrix | School (yes/no) and Tuition (yes/no) are independent date-specific commitments. All four combinations (Both, School-only, Tuition-only, Neither) calculate free study time deterministically. |
| D07 | 2026-11-21 | **Confirmed** | Design Language | Apple-inspired Liquid Glass with translucent frosted surfaces (`backdrop-filter: blur()`), fine glass borders, layered depth, blush/rose palette, and high-contrast deep plum text (`#493542`). |
| D08 | 2026-11-21 | **Confirmed** | Zero Cost & Privacy | Zero paid APIs, no third-party LLM costs, offline PWA capability, on-device document extraction via PDF.js/Tesseract.js, and client-side encryption. |

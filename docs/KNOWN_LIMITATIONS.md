# BLOOM Rebuild — Known Limitations & Boundaries

1. **Academic Scope:** Strictly CBSE Class XII Board Examinations (2027 session). Does not support Class XI, JEE Main, JEE Advanced, NEET, or state boards.
2. **CBSE Weightage Granularity:** CBSE officially publishes marks allocation at the Unit level or grouped-unit level (e.g. Physics Units I–II = 16 marks; Mathematics Calculus = 35 marks) and explicitly notes that no individual chapter-wise weightage is provided. BLOOM adheres strictly to official CBSE scopes and will never fabricate individual chapter exam mark predictions.
3. **Single-User Privacy:** Designed exclusively for Aastha. There are no shared multi-student rosters, external reviewer accounts, or parent surveillance portals.
4. **Local-First & Offline:** All core planning, focus timing, question logs, and document parsing run locally on the client. Cloud sync requires student authorization and client-side encryption.
5. **Zero-Cost Constraint:** No paid third-party APIs (including OpenAI, Anthropic, or paid Gemini tiers) are required or authorized. All study planning and schedule optimization run deterministically.
